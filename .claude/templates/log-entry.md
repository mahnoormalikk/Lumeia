# Log entry — <change name>

Use this shape for the build-log entry at /ship, and condense it to one line in DECISIONS.md.

- **Date:** YYYY-MM-DD
- **Change / branch:** `change-<short-name>`
- **Outcome:** shipped to dev / blocked / parked
- **What changed:** one or two lines
- **Scope:** once (store-level) / twice (both PDP templates, in sync)
- **Verify evidence:** pull-verified (file:line + string) · desktop (what was checked) · mobile (screenshot or script result)
- **Review:** reviewer verdict (approve / approve-with-suggestions / was blocked then fixed); anything carried forward
- **Live:** on dev; published to live? (Stelios, date) — never auto
- **Follow-ups / notes:**

One-line DECISIONS.md form: `YYYY-MM-DD · <change> · shipped-to-dev · <evidence in a few words>`
